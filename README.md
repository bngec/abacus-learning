 🧮 Abacus Learning App

 BN Global Education Centre

Make mathematics fun with interactive abacus learning! Our Android app helps students practise abacus calculations through an engaging, child-friendly experience.

 ✨ Features

- 🧮 Interactive virtual abacus
- 🎨 Child-friendly interface
- 🔢 Abacus calculation practice
- 🎵 Interactive sounds and animations (where available)
- 📱 Android app support

 📥 Download the Android App

**Latest Release:** [Download Abacus Learning App](https://github.com/bngec/abacus/releases/latest)

1. Open the release page.
2. Scroll down to **Assets**.
3. Download the `.apk` file.
4. Open the downloaded APK on your Android device to install it.

If the download link does not work, visit the repository's Releases section after a release has been published.
